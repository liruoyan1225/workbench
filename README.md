# 个人综合工作台 · Personal Workbench

一个单文件 HTML 的科研/学习综合工作台，双击即用，数据保存在本机浏览器（localStorage），可导出/导入备份。

## 功能模块

- **首页全景**：实时时钟、节日倒计时、便利贴、本月日历、近期行程、跨模块待办汇总
- **课题 Idea**：收藏课题灵感、相关公众号与论文，支持类型标签（想法/公众号/论文）、链接、搜索筛选
- **仿真实验**：记录仿真名称、环境、参数、结果、状态
- **任务管理**：待办 / 正在进行 / 加急处理 / 已解决 四态看板
- **工作台**：完整任务机制——任务池（悬赏中）→ 今日追杀令（攻坚中，含计时器）→ 战果（干掉了），带常驻计时器与本周战果统计

## 使用方式

- 直接双击 `personal-workbench.html` 在浏览器打开即可
- 或在同目录下运行 `launch-workbench.bat`（用 Chrome 无地址栏应用模式打开，更像桌面 App）
- 本地部署：在本目录执行 `python3 -m http.server 8080 --bind 127.0.0.1`，访问 `http://127.0.0.1:8080/personal-workbench.html`
- 公网访问（GitHub Pages）：https://liruoyan1225.github.io/workbench/

## 说明

- 头像以 base64 内联在 HTML 中，单文件自包含，移动文件不会丢失
- 所有数据存于本机浏览器，不上传任何服务器
